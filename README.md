## 📚 3. 학습 앱

### 앱 이름

**CSR vs SSR 렌더링 시각화 학습기**
_CSR과 SSR의 렌더링 흐름을 브라우저 시뮬레이션으로 직접 체험하며 FCP와 TTI 차이를 눈으로 확인하는 웹 학습 도구_

### 배포 링크

https://gemini.google.com/share/b90212204309

### 이 앱을 만든 이유

- **어떤 문제/불편함을 해결하려고 했나요?**
  CSR과 SSR의 차이를 글로만 읽었을 때는 머릿속에 잘 그려지지 않을 수 있다.
  FCP, TTI 같은 개념이 실제로 어떤 시점에 일어나는지 텍스트로는 체감하기 어려울 수 있고, 특히 SSR의 Hydration 전후 차이는 직접 겪어보지 않으면 이해하기 힘든 개념이라고 생각해서 시각화 해보고 싶었다.
  <br>
- **본인이 이 앱을 언제, 어떻게 사용할 건가요?**
  렌더링 방식을 처음 배우는 시점에 열어두고, 개념 설명을 읽으면서 시뮬레이션을 함께 돌려보는 방식으로 사용할 것이다.
  또한 면접 전 개념을 빠르게 복습할 때도 활용할 수 있다고 생각한다.

### 주요 기능

- **CSR / SSR 시뮬레이션**: 브라우저 목업 위에서 각 렌더링 방식이 단계별로 어떻게 진행되는지 타임라인과 함께 시각적으로 보여준다.
- **FCP / TTI 실시간 타이머**: 화면이 처음 표시되는 시점(FCP)과 실제로 상호작용이 가능해지는 시점(TTI)을 ms 단위로 측정해 두 방식의 차이를 수치로 비교할 수 있다.
- **Hydration 체험**: SSR 시뮬레이션에서 JS 로드 전 버튼을 클릭하면 아무 반응이 없고, Hydration 완료 후에야 정상 작동하는 것을 직접 눌러볼 수 있다.

## 🤝 4. 페어 프롬프트 릴레이 앱

### 앱 이름

**친해지길 바래**
_처음 만난 사람들과 핀볼 게임으로 랜덤 그룹을 뽑아 어색함을 없애주는 모임 아이스브레이킹 서비스_

### 페어

[@juhyeong424](https://github.com/juhyeong424)
[@geongyu09](https://github.com/geongyu09)

### 배포 링크

https://gemini.google.com/share/3304f5bbce38

### 이 앱을 만든 이유

- **어떤 문제/불편함을 해결하려고 했나요?**
  처음 만나는 사람들끼리 어색하게 서 있는 상황, 누구나 한 번쯤 경험해봤을 것이다.
  특히 새로운 모임이나 행사에서 "자유롭게 팀을 짜세요"라고 하면 결국 아는 사람끼리만 뭉치게 되는 문제가 있었다.
  이 앱은 그 어색함을 게임으로 풀어내서, 랜덤 그룹핑 자체가 하나의 재미있는 경험이 되도록 만들었다.
  <br>
- **본인이 이 앱을 언제, 어떻게 사용할 건가요?**
  우테코 OT, 동아리 OT, 네트워킹 행사, 워크숍처럼 처음 보는 사람들이 모이는 자리에서 사용할 것.
  진행자가 화면을 띄워놓고 참여자들이 자기 이름을 직접 입력한 뒤, 다 같이 핀볼 애니메이션을 보면서 어느 팀에 들어갈지 두근두근 기다리는 방식으로 활용할 수 있다.

### 주요 기능

- **핀볼 기반 랜덤 그룹핑**: 참여자 이름이 공이 되어 핀볼 보드 위에서 떨어지며 그룹에 배정된다. 단순한 추첨이 아니라 공이 페그(장애물)에 부딪히며 튀어나가는 물리 시뮬레이션으로 결과를 예측하기 어려워 더 재미있다.
- **균등 분배 보장**: 그룹 정원이 다 차면 해당 그룹 입구가 막혀 공이 튕겨 나가고,모든 그룹에 인원이 최대한 균등하게 배정된다.
- **판 흔들기**: 게임 도중 공이 끼거나 흐름이 막혔을 때 판을 흔들어 공들에게 물리적인 충격을 줄 수 있다. 중간중간 판을 흔들면서 관전하는 재미가 있다.
